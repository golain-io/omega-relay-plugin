# Omega Relay listing assets

The Omega Relay mark is an open ring with one dot resting in the opening. These four files are the same mark, generated from one source, and belong to Golain Systems Private Limited.

| File | Manifest field | What it is |
| --- | --- | --- |
| `omega-relay.svg` | `logo`, Claude `icon` | The app icon: iris mark on a haze tile, 1024 × 1024. The same file as the desktop app's icon. |
| `omega-relay-dark.svg` | `logoDark` | White mark on an ink tile, 1024 × 1024. |
| `composer-icon.svg` | `composerIcon` | The mark alone, 120 × 120, transparent. |
| `composer-icon-dark.svg` | `composerIconDark` | The mark alone in white. |

All four are plain shapes: no scripts, links, fonts or embedded images. Brand colour: `#6558C8`.

In the source repository they are written by `brand/build-icons.py`; change the mark there, not here. PNG renders of the logo at 512 and 1024 pixels are in `brand/icons/listing/` for a form that wants a raster upload.
